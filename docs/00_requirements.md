# 要件定義

作成日: 2026-09-21

---

## 1. 背景

RAG は動くものを組むまでが速い一方で、改善に入ると途端に判断が難しくなる。
チャンクサイズを変えた、top-k を増やした、再ランクを入れた——そのそれぞれが精度にどう効いたのかは、固定した評価セットと指標がないと比較できない。結果として「体感で良くなった」以上のことが言えなくなり、変更を戻す判断も、続ける判断もできなくなる。

このリポジトリは、RAG のパイプラインそのものではなく、**その比較を成立させる仕組み**を作ることを目的とする。

## 2. 目的

1. RAG の設定を変えたときの精度変化を、同一の評価セットと指標で比較できるようにする
2. 実験条件を宣言的に記述し、再現できるようにする
3. 実験結果を人が読める形で残し、判断の根拠を後から追えるようにする
4. 評価を CI に組み込み、変更による精度劣化を自動で検知する

## 3. スコープ

### やること

| # | 項目 | 内容 |
|---|---|---|
| F-1 | 文書投入とチャンク分割 | コーパスを読み込み、指定された戦略でチャンクに分割する |
| F-2 | 埋め込み | チャンクをベクトル化する。プロバイダは差し替え可能 |
| F-3 | 索引と検索 | Vector DB に格納し、クエリに対して top-k を返す。再ランクの有無を切り替えられる |
| F-4 | 生成 | 検索結果を文脈として回答を生成する。出力は構造化して検証する |
| F-5 | 評価 | 検索側と生成側の指標を算出する |
| F-6 | 実験の宣言と実行 | 条件を YAML で定義し、コマンド一発で実行する |
| F-7 | 結果の出力 | 条件 × スコアの表を Markdown で出力する |
| F-8 | 回帰検証 | スコアが閾値を下回ったら CI を落とす |

### やらないこと

意図的に外したもの。スコープを広げると「何を比較する道具なのか」がぼやけるため。

- Web UI・API サーバー（この道具は CLI で完結させる）
- 埋め込みモデル自体の学習・ファインチューニング
- マルチモーダル（画像・音声）への対応
- 本番運用を想定したスケーリング・永続化
- 回答の自然さ・流暢さの評価（人手評価が必要な領域のため）

## 4. 品質要件

| 項目 | 基準 |
|---|---|
| 再現性 | 同じ YAML と同じ評価セットから、同じ結果が得られること（生成のばらつきは temperature=0 と seed 固定で抑える） |
| テスト | パイプライン各段に単体テストを置く。外部 API はモックする |
| 型 | 実験条件と生成出力を Pydantic で型定義し、実行前に検証する |
| 外部呼び出し | 埋め込みと生成にタイムアウト・指数バックオフのリトライ・レート制限を入れる |
| 観測 | 各実行でトークン数・所要時間・推定コストを記録する |
| 静的解析 | ruff（lint / format）と mypy を CI で必須化する |

## 5. 前提と制約

- 埋め込みと生成は外部 API に依存する。API キーは `.env` で与え、リポジトリにはコミットしない
- 評価用コーパスは再配布可能なライセンスの公開文書のみを使う。出典とライセンスを明記する
- 評価セットは自作する。件数は 40〜60 件を目安とし、それ以上は増やさない（作成と検証に時間がかかりすぎるため）
- ローカル実行を前提とする。クラウド上での実行手順は補助的に用意する

## 6. 成功の判定

このリポジトリは、以下が満たせたら目的を達成したとみなす。

1. `uv run rageval run <yaml>` の一行で、条件を変えた実験が回ること
2. 5 パターン以上の条件で実験を回し、条件 × スコアの表が `docs/04_results.md` に残っていること
3. その表から「どの条件が効いたか」について、根拠のある考察が1つ以上書けること
4. CI が緑であること（テスト・lint・型・評価の回帰検証）

## 7. 用語

| 用語 | 定義 |
|---|---|
| チャンク | 文書を検索単位に分割したもの |
| 重複幅（overlap） | 隣接するチャンク同士が重なる文字数 |
| top-k | 検索で取得する上位件数 |
| 再ランク | 検索結果を別のモデルで並べ替え、関連度の高い順に整えること |
| 評価セット | 質問と、その正解根拠となるチャンクの対の集合 |
| 根拠一致 | 生成された回答が、正解根拠のチャンクに含まれる情報に基づいているか |
